# TishaCare

Цифровая платформа мониторинга пациентов с БАР (по мотивам ВКР). MVP из двух частей:

- **apps/bot** — Telegram-бот для пациентов (Telegraf + Scenes): привязка по коду приглашения, ежедневный чек-ин (настроение/сон/энергия/лекарства), опросники Бека и MDQ, учёт медикаментов, дневник мыслей, чат поддержки на GPT, напоминания.
- **apps/web** — веб-панель врача (Next.js): список пациентов, график динамики настроения, анамнез, результаты опросников с интерпретацией, медикаменты, дневник мыслей.
- **packages/db** — общая Prisma-схема + клинический контент (вопросы и подсчёт баллов Бек-21/MDQ), используется и ботом, и веб-панелью.

## Установка

```bash
npm install
npm run db:push
npm run db:seed
```

Сид создаёт демо-клинику, врача (`doctor@demo.local` / `demo1234`) и двух пациентов с историей чек-инов, опросников, медикаментов и записей дневника.

## Запуск веб-панели

```bash
npm run web
```

Откройте http://localhost:3000 и войдите демо-доступом.

## Запуск бота

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен.
2. Скопируйте `apps/bot/.env.example` в `apps/bot/.env` и впишите `TELEGRAM_BOT_TOKEN`.
3. (Опционально) впишите `OPENAI_API_KEY`, чтобы включить сцену GPT-поддержки — без ключа бот работает нормально, просто сообщает, что эта функция недоступна.
4. Запустите:

```bash
npm run bot
```

5. В Telegram отправьте боту `/start КОД_ПРИГЛАШЕНИЯ` (код пациента печатается в консоли после `db:seed`) и пользуйтесь меню внизу экрана.

## Что перенесено из старого прототипа (2024, Python)

В проект попал более ранний прототип на python-telegram-bot с реальным клиническим контентом. Из него портированы в новый стек:

- Опросник депрессии Бека (21 вопрос) и MDQ (скрининг биполярного спектра) — с полным текстом вопросов и логикой подсчёта.
- Учёт медикаментов (добавить/изменить/удалить).
- Дневник мыслей.
- Чат поддержки на GPT (с исправленным багом старого кода — раньше в диалог сохранялся объект ответа API вместо текста).

Три сознательных отличия от оригинала:

1. **MDQ считается по клиническим критериям** (≥7 «да» из 13 симптомов + совпадение по времени + умеренное/серьёзное влияние), а не простой суммой всех ответов, как было в старом коде — та реализация давала статистически необоснованный результат.
2. **Отдельный CRUD настроений/сна убран** — эти данные собираются через единый /checkin (сон+настроение+энергия+лекарства за один короткий проход), что лучше соответствует цели диплома «снизить когнитивную нагрузку», чем несколько разрозненных пунктов меню.
3. **График настроения в боте — текстовая сводка**, а не картинка (в старом коде — matplotlib). Полноценный интерактивный график остаётся в веб-панели врача; добавлять генерацию изображений в бота отдельным native-модулем не стали, чтобы не усложнять деплой.

## Когнитивный тест (Telegram Mini App)

Кнопка «🧩 Когнитивный тест» открывает патопсихологическую батарею из 9 субтестов (память, внимание, мышление, речь, пространственная ориентация, регуляция и контроль, психологическое состояние) как Telegram Mini App — веб-страница `apps/web/app/miniapp`, авторизация пациента через Telegram `initData`. Тесты и подсчёт баллов — в `packages/db/cognitive.ts`, по образцу `clinical.ts` (Бек/MDQ). Пороги «норма/ниже нормы» — эвристические, MVP-уровня, не валидированы специалистом.

**Сознательное отличие от оригинала**: субтест на регуляцию/контроль в исходнике использовал аудио (нажать на пробел, услышав букву). Воспроизведение звука внутри встроенного WebView Telegram (особенно на iOS) ненадёжно, поэтому используется визуальный вариант go/no-go — буквы вспыхивают на экране, а не звучат.

⚠️ В архиве со старым прототипом были закоммичены реальные Telegram-токен и OpenAI-ключ. Они не переносились в этот репозиторий — если ещё не сделали, отзовите их (BotFather `/revoke`, OpenAI → удалить ключ).
