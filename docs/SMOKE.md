# Смоук-чеклист приёмки

Ручная проверка перед выкаткой в прод (после того, как CI зелёный и ветка
задеплоена на staging). ~10 минут. Прогонять на **staging**-контуре.

## Бот и онбординг

- [ ] `/start` у бота контура → приходит приветствие с кнопкой «Открыть приложение»
- [ ] повторный `/start` → «С возвращением», без дубля пациента
- [ ] кнопка открывает Mini App внутри Telegram, не в браузере
- [ ] новый пациент → админу приходит уведомление (если задан `ADMIN_TELEGRAM_ID`)

## Mini App (пациент)

- [ ] первый вход без даты рождения → редирект на онбординг профиля; вводится **полная дата** (день-месяц-год)
- [ ] чек-ин: настроение/сон/энергия/лекарства сохраняются, повторный заход показывает историю
- [ ] «Моя динамика»: график настроения/сна/энергии, переключатель 7/30/90 дней работает
- [ ] опросник Бека проходится, показывает интерпретацию
- [ ] MDQ проходится, показывает результат
- [ ] когнитивный тест: все 9 субтестов открываются, результат сохраняется
- [ ] медикаменты: добавить / изменить / удалить
- [ ] дневник мыслей: запись сохраняется
- [ ] GPT-поддержка отвечает (или корректно сообщает о недоступности без ключа)

## Веб-панель (врач)

- [ ] логин демо-доступом, редирект на `/dashboard`
- [ ] список пациентов, у каждого — свежие данные
- [ ] карточка пациента: график самочувствия, баллы опросников, когнитивные категории
- [ ] редактирование анамнеза сохраняется
- [ ] «Подключить пациента» по коду приглашения работает
- [ ] логаут → редирект на `/login`, `/dashboard` больше не открывается

### Регистрация врача (`/register`)

- [ ] «Работаю в клинике» + название → создаётся клиника, врач попадает на `/dashboard`, в topbar её название
- [ ] «Самозанятый» → врач без клиники, в topbar «Частная практика»
- [ ] повторная регистрация на тот же email → ошибка «уже зарегистрирован» (клиника-сирота не создаётся)
- [ ] короткий пароль / кривой email / клиника без названия → понятная ошибка

## Веб-портал пациента (`/app`)

- [ ] `/app` без сессии → редирект на `/app/login`
- [ ] регистрация нового пациента (имя/email/пароль) → попадает в `/app`
- [ ] вход существующего пациента по email/паролю → онбординг (согласие → полная дата рождения) → меню
- [ ] неверный пароль 5 раз → аккаунт блокируется на 15 мин (даже с верным паролем — `429`)
- [ ] «Моя динамика» на `/app/progress`: график рисуется, переключатель диапазона работает
- [ ] чек-ин на `/app/checkin` сохраняется, виден в истории и на графике врача
- [ ] Telegram-пациент в профиле Mini App может задать email+пароль и затем войти на `/app` теми же данными
- [ ] логаут в `/app` → редирект на `/app/login`, `/app` больше не открывается

## Напоминания

- [ ] ручной вызов `/api/cron/reminders` с `Authorization: Bearer $CRON_SECRET` → `{ ok: true, sent: N }`
- [ ] без заголовка / с неверным секретом → `401`
- [ ] пациенту, не отметившемуся сегодня, приходит напоминание; отметившемуся — нет

## Контур

- [ ] на проде `MINIAPP_DEV_BYPASS` не задан (иначе деплой падает — это ожидаемо)
- [ ] `WEBAPP_URL` в кнопке бота ведёт на этот же контур
