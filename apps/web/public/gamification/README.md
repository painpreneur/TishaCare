# gamification assets ("Плотина Тиши")

Source set generated by ChatGPT (soft-outline cartoon style, transparent PNG).
Originals were 2048² RGBA with a real alpha channel; here they are downscaled
(premultiplied LANCZOS) and re-optimised. `DamScene` / `MilestoneCard` reference
them via `next/image` at `/gamification/<name>`.

Тиша stays IN each stage scene, so no separate sprite is composited on top of a
scene. The `tisha-today-*` sprites are shown small beside the status line.

`DamScene` picks the seasonal stage-6 by month; `stage-6.png` is the fallback.

## Milestone cards — 1024², transparent

`milestone-1.png` … `milestone-6.png` — close-ups of stage scenes 1..6.
The confetti burst is code (canvas-confetti), never baked into the image.

## Quality check (post-process)

All 20 files: background fully transparent (51–74% of pixels), semi-transparent
near-white fringe < 0.1%, zero baked-white regions. No matte cleanup needed.
